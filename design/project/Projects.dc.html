BookScout

Is this book a first edition? Upload a photo of the copyright page. Claude vision reads it, a web-search agent researches the edition, and you get a verdict with a confidence score, an estimated value and sources.

  • A cover only identifies the work, so the edition needs a copyright page.
  • Working web beta with 87 offline tests.
  • Checked end to end on an iPhone photo of The Three-Body Problem (Tor, 2014).

TravelScout

Does this flight cross dangerous airspace? TravelScout maps the route between two places and steers around the zones you mark as unsafe.

  • Draws the great-circle path and shades the danger zones.
  • Reroutes around them and shows the added distance.
  • Gives a live risk read from Claude web search, with cited sources.
  • Runs on mock data until you add API keys.

TestCube

A vision component for Rubik's cubes. It takes a photo of one cube face and returns nine 64×64 facelet images, ordered top-left to bottom-right, ready for a colour-recognition step.
